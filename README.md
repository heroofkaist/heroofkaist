### About me

I'm a student at KAIST who enjoys physics, programming, and learning new things through hands-on projects.

I've always enjoyed figuring out how things work, especially when math and physics come together. I like building simulations, working with data, and using code to explore ideas that would be difficult to test otherwise. Over the years, I've worked on everything from physics olympiad problems to astrophysics research and software projects.
